Efectos de sonido con licencia (wav/mp3). El nombre del archivo se usa para emparejar con el
campo `sfx` del guion: p.ej. `engine_rev_sportscar.wav`, `city_ambience_night.wav`, `helicopter.wav`,
`siren_police.wav`, `boat_engine.wav`, `footsteps_street.wav`, `riser.wav`.
El whoosh y el impacto del gancho se sintetizan automáticamente si no hay archivo.
